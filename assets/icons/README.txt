Optional. The site already has built-in SVG icons, so this folder can stay empty.

To use real image files instead, drop square PNGs here and uncomment the matching
lines under `icons` in js/config.js. For example:

  assets/icons/finder.png   ->   finder: "assets/icons/finder.png",

Recognised ids: folder finder mail notes photos safari user doc pdf github linkedin
Any id you don't list keeps its built-in SVG, so you can override just one or two.
